# Northstar — Online Proposal Portal

A responsive proposal-management starter for agencies and consulting teams. Built as a zero-build static app with HTML, CSS, and vanilla JavaScript.

## Features
- Overview dashboard with proposal metrics and recent activity
- Proposal library with search and status filtering
- Proposal builder with live client preview
- Share-style client proposal view with approve and request-changes interactions (demo only)
- Workspace settings screen
- Responsive layout for desktop, tablet, and mobile

## Run locally
Open `index.html` in a browser. No install or build step is required.

## Notes
This is a front-end prototype. Proposal records are in-memory demo data; approval, feedback, persistence, authentication, and shareable public links are not connected to a backend yet.

## Next steps
Connect a database and authentication, persist proposal records, generate secure client URLs, and route approval/comments to an API.
